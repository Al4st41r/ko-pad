# Sounds

No sounds are included with KO Pad. Put your own here, or import them in the app.

Files in this folder appear as sample numbers 1 to 599. Name the source WAV files `NNN_name.wav` and run `tools/convert_samples.sh /path/to/your/wavs` from the repository root. It writes `NNN.flac` files and `catalogue.json` into this folder.

Everything in this folder except this note is excluded from git, so your sounds stay out of any public copy. See "Adding your own sounds" in the main README.
